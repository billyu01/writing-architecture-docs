# 配图质量检查与修复

> 顺序：先跑机器检查，再做视觉终检；机器只能查硬缺陷，表达是否清楚必须人看。

## 1. 机器检查（16 项）

| # | 检查项 | 自动查法 | 不合格修法 |
|---|---|---|---|
| 1 | 文字溢出容器 | 按字号估宽（中文×1.0、西文×0.6），与所属盒子/画布边界比，留 ≥2px | 先改短文案，其次加大盒子，最后减字号 |
| 2 | 文字溢出画布 | 估宽与 `viewBox` 宽高比 | 扩 viewBox 或拆图 |
| 3 | 标签遮罩压节点 | 小矩形（高≤18）与后画节点矩形求交；完全在节点内=合法徽标 | 挪到空白走廊或做成徽标 |
| 4 | 标签遮罩压自己的线 | 遮罩与线距离 <6px | 遮罩上移，保持 6–10px |
| 5 | 分区包含 | 节点矩形必须完全落在某个分区内 | 挪节点或扩分区；跨区说明分区切错 |
| 6 | 连线端点落在节点边 | 解析 path 起止点，与节点矩形四边比对（容差 ≤3px） | 按节点真实坐标重算端点；先取 rect 再写 path |
| 7 | 连线穿过非端点盒 | 折线水平/垂直段与非端点节点求交 | 绕行；绕不开改虚线并在可见端放标签 |
| 8 | 多条线重叠 | 共线线段两两求交 | 平行偏移 ≥12px 或重排 |
| 9 | marker 引用存在 | 每个 `url(#…)` 在本文档有对应 id | 补 marker；前缀时同步改引用 |
| 10 | 跨图 id 冲突 | 整页 id 计数 >1 即失败 | 构建时按图加前缀 |
| 11 | 跨图 class 冲突 | 统计每个 `<style>` 同名选择器；声明不一致=失败 | class 加图前缀并同步 `class=` |
| 12 | 页面横向滚动 | 渲染后 `scrollWidth > clientWidth`；或查 `overflow-x:auto`/`min-width` | 去掉固定宽/滚动样式，`width:100%;height:auto` |
| 13 | 纵向裁切 | 容器高 < viewBox 换算高 | 按公式改容器或 `height:auto` |
| 14 | 中文渲染 | 无头浏览器截图确认无方框/字体回落 | 补 `Noto Sans TC/SC` 回退链 |
| 15 | 导出/嵌入变形 | 对比导出 SVG 与源 `viewBox`；检查残留 `width="100%"` | 导出保留 viewBox，宽高交 CSS |
| 16 | 构建可重复 | 连跑两次 `shasum` 比字节；无残留占位符；图数正确 | 占位符+映射表，产物入库前 diff 干净 |

现成脚本：
```bash
python3 scripts/check_architecture_diagrams.py docs/architecture/arch.html
python3 scripts/embed_svg.py --manifest docs/architecture/figures.json
```

脚本查不到、必须人工的：表达是否清楚、信息层次、焦点是否 1–2 个、减少测试是否还能懂。

## 2. 视觉终检（固定动作，不是「看一眼」）

1. 无头浏览器按目标宽度截图（如 1720×1400，缩放 1）；建议用本技能 `../scripts/render_check.py`。
2. 整图看一遍：有没有空白块、缺图、明显错位。
3. 按区域裁剪放大：每个分区、图例、最长的标签各裁一张。
4. 窄屏再截一次（如 900px 宽），确认没有横向滚动、文字没被压扁。
5. 对照正文读一遍图：图上的东西正文都有解释，正文提到的东西图上都找得到。

无法截图时，必须明说「我无法验证视觉，请你在浏览器确认，若有问题告诉我具体哪张图哪个位置」——不得默认「应该没问题」。

## 3. 修复手法库

| 症状 | 先试 | 再试 | 最后 |
|---|---|---|---|
| 文字出框 | 缩短文案（保留关键信息） | 加大盒子/换行/移位 | 减字号（会破坏层级，慎用） |
| 连线断开/悬空 | 从节点矩形取真实边坐标重算 | 调整端口位置（同边散开 ≥12px） | 改布局让关系更直 |
| 连线穿盒 | 绕行 | 调换节点顺序 | 拆图（总览 + 详图） |
| 多图叠加/样式串 | 给 class 加图前缀 | 给 id/marker/title/desc 加前缀 | 拆成独立页面 |
| 图有滚动条 | 去 `min-width`/`overflow-x` | `width:100%;height:auto` | 减小 viewBox 宽 |
| 图被裁切 | 按 viewBox 算容器高 | 去掉固定高 | 图缩放到容器 |
| 中文变宋体/等宽错位 | 补 Noto 字体 link | 调整回退链 | 换字体许可范围内方案 |
| 图与正文不一致 | 以正文/术语表为准改图 | 补图注说明 delta | 重新画 |

## 4. 修复后复验

- 同一条检查命令重跑，问题归零。
- 截图对比修前/修后（至少整图 + 问题区域）。
- 更新图索引、图注、修订史；如果改了图源，重新导出并重建 HTML。
- 把新出现的症状沉淀成检查项：下一次不靠眼睛。
