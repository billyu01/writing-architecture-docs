# 画图流水线与布局规则

## 1. 十步法

| # | 步骤 | 做什么 | 检查点（不合格退回上一步） |
|---|---|---|---|
| 1 | 判断要不要画 | 读者问题、钉哪条约束、表能否替代 | 说不出问题 → 改表 |
| 2 | 定图种 | 先语义模式（行为/状态/风险），再视觉类型 | 已读对应 type 参考 |
| 3 | 定内容与预算 | 列节点/连线/分区，标 1–2 焦点 | 在复杂度预算内；超了拆总览 + 详图 |
| 4 | 定画布尺寸 | 目标嵌入宽度（内联 960–1200，宽图 1200–1400）；`viewBox` 匹配内容 | 宽高比接近容器 |
| 5 | 读技能 | `diagram-design` SKILL → style-guide → type 参考 → template | 颜色/字体全部取自 style-guide |
| 6 | 画 | 背景 → 分区 → 连线 → 盒子 → 标签 → 图例 | 连线先画（在盒子下层）；文字最后 |
| 7 | 机器自检 | `self_check.py` + 本技能几何/文字/命名空间检查 | 全 `OK` |
| 8 | 视觉终检 | 无头浏览器截图整图 + 局部裁剪 + 窄屏 | 亲眼确认无重叠/裁切/溢出 |
| 9 | 导出 | 按 `diagram-design` 导出流程抽 `<svg>` | 导出物 viewBox 与源一致 |
| 10 | 嵌入文档 | 占位符构建或内联；id/class 前缀；更新索引 | 构建断言通过；浏览器完整可见 |

## 2. 派工书模板（给画图子代理）

```markdown
## 技能加载（必须照做，不可跳）
1. 风格总纲：<绝对路径>/references/style-guide.md
2. 类型参考：<绝对路径>/references/type-<type>.md
3. 模板基座：<绝对路径>/assets/template.html
4. 既有同类资产（风格已验证；中文标签照抄其 fonts link）：<绝对路径>
5. 产出后必跑：python3 <绝对路径>/scripts/self_check.py <产出文件>，把输出贴进回复

## 图内容（预算：<硬数字>）
<逐项列节点、字段、连线、标注；超预算时给取舍许可>

## 语义要求
<焦点 1–2 个、每类节点标记、图题与副标题原文>

## 产出
仅一个自包含 HTML：<绝对路径>
<自检清单：role/aria/title/desc 前缀、直角圆弧 r=8、箭头先画、标签遮罩 6–10px、图例底部、4px 网格>

## 回执（≤12 行）
文件路径 + self_check 尾行 + 预算数确认 + 取舍说明

## 中断兜底
先把文件写盘、再自检、最后回执；任何一步失败先把已完成部分留在路径上。
```

**产出物契约**：一次画图至少留下四样——HTML 源、导出的 SVG、自检输出原文、取舍说明。只留图片或聊天记录，后续无法复现。

## 3. 通用布局规则（所有图种）

1. **分区先于一切**：先切 2–4 个有真实含义的区（环境/信任边界/调用层次），再放节点。分区必须是真实边界，不是视觉分组。
2. **层级靠差异，不靠装饰**：焦点用强调色（每图 ≤2 个），其余用墨色/次要色；不要靠阴影、渐变、圆角大小分层。
3. **命名三件套**：人读的名字（无衬线）+ 技术副标签（等宽：端口/版本/协议）+ 类型标记（等宽小标签）。
4. **中文宽度按全角算**：中文 = 字号 ×1.0，西文 ×0.6，空格 ×0.3；这是文字溢出检查的基础。
5. **中文字体有回退链**：`'Geist','Noto Sans TC',system-ui,sans-serif`；衬线 `'Instrument Serif','Noto Serif TC',serif`；等宽 `'Geist Mono','Noto Sans TC',ui-monospace,monospace`。只写英文字体，中文会落到系统默认，字号与基线全变。
6. **留白走网格**：结构尺寸（坐标/宽高/间距/内边距）4px 网格；字号不必对齐；间距只用 20/24/32/40/48。
7. **标签必须带不透明遮罩**：否则连线从字里穿过。
8. **标签与线留 6–10px 可见间隙**：遮罩不能压住自己那条线。
9. **遮罩不能压到后画的盒子**：节点后画，遮罩落进节点会被填充裁掉一半；要么挪到空白走廊，要么做成节点内徽标。
10. **箭头先画、盒子后画**：z 序保证线在盒子下，线头被盒子边缘自然切断。
11. **连线走直角圆弧**：不同行节点之间用直角折线 + r=6~8 圆角；斜线是硬性不合格。
12. **一条边多个接点要散开**：按 `L*k/(N+1)` 分布，相邻 ≥12px，全程并行间距 ≥12px。
13. **连线不得从非端点盒子背后穿过**：绕行优先；绕不开改虚线并在可见端放标签。
14. **图例放画布底部横条**，不要浮在图中；画布高度相应加约 60px。

## 4. 时序图专属

1. 参与者横排上方，生命线虚线竖线，时间从上往下。
2. 消息箭头只向下；返回虚线 + 实心箭头；异步空心箭头。
3. 激活条表示「谁在控制」，嵌套调用叠起来且必须闭合。
4. 自调用用 U 形回环，标签放回环右侧，不压生命线。
5. 分支必须用条件片段框，不许自由箭头簇表示 if/else。
6. 片段框比参与生命线外扩 ≥12px；框内消息 y 间距 ≥24px；嵌套 ≤1 层。
7. 操作符标签等宽大写（`ALT`/`OPT`/`LOOP`）写左上角标签页；守卫条件写标签页下方。
8. 焦点色只给一条「主成功返回」消息。
9. 验收点若画成自环，拐角必须圆弧，标签避开环线。

## 5. 部署图专属

1. 三层嵌套：分区 → 节点 → 部署物（artifact）；分区先画，节点其次，部署物最后。
2. **部署物必须带版本**：没版本等于白画，版本正是这张图存在的理由。
3. 副本数用节点右上角小徽标，不要为每个副本画节点。
4. 跨分区连线用外链色，分区内部用次要色，异步/复制用虚线。
5. 连线标协议与端口（`HTTPS:443`、`TLS:5432`）。
6. **连线端点落在节点本体，不是分区边界**：画完逐条核对 path 起止坐标是否等于节点矩形某条边。
7. 分区标签垫纸色遮罩压在分区边框上，避免和边框重叠。
8. 一个节点多个部署物时纵向堆叠、间距 8px；不要横向挤一行。
9. 一个分区放不下就拆图（每个环境一张），不要把两个环境塞进一张。

## 6. 领域模型（ER）专属

1. 实体框两段式：头部（类型小标签 + 实体名），主体（字段列表，每行一个）。
2. 主键 `#`、外键 `→`，类型/枚举用等宽小字。
3. 关系两端都标基数（`1`/`N`/`0..1`/`1..*`），写法全图统一。
4. 关系聚集摆放，让大多数关系线是直线。
5. 超出实体预算的账本/日志类集合用斜体旁注说明，不要硬塞第 9 个实体。

## 7. 三个「看起来对但一定会坏」的坑

1. **坐标即契约**：手算 x/y 必须与最终 `rect` 定义同一组数字；改布局就重算端点，目测必然差 4–28px。
2. **样式作用域即隔离**：内联多张 SVG 时 `<style>` 是全局的，短类名会跨图覆盖，表现为「第 N 张图的文字叠到上一张」。
3. **画布尺寸即渲染预算**：`viewBox` 高 1064 的图塞进 900px 高的容器，底部被裁且不报错。

## 8. 反模式速查（来自 diagram-design）

深色底 + 青紫发光；满屏等宽字体；所有节点同样方框；图例浮在图中；箭头标签无遮罩；竖排文字；3 张等宽摘要卡；阴影；大圆角；每图超过预算不拆；用 Mermaid 自动布局冒充设计。
